## 📌 About

This repository contains implementations of **Machine Learning** and **Deep Learning** algorithms using **Python**.

The goal of this project is to:

- 📖 Understand the mathematics behind each algorithm
- 🛠️ Implement algorithms from scratch whenever possible
- 📊 Visualize results using plots
- 📚 Build a comprehensive ML learning repository
- 💼 Showcase practical ML skills

# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/your-username/Machine-Learning-Algorithms.git
```

Move into the project

```bash
cd Machine-Learning-Algorithms
```

Create a virtual environment

```bash
python -m venv .venv
```

Activate it

### Windows

```bash
.venv\Scripts\activate
```

### macOS/Linux

```bash
source .venv/bin/activate
```

Install dependencies

```bash
pip install -r requirements.txt
```
